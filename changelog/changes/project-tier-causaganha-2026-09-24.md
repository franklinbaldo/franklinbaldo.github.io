# Canonical project tier: CausaGanha

Adds `knowledge/project-tiers/causaganha.md` for `franklinbaldo/causaganha`, reviewed at main revision `4709458aeaf8f67c3b69ee3a28864204a3db9848`.

The initial placement is **quality A / interest S / medium confidence**. The review credits the separation between archive/state/content evidence, public Internet Archive + Parquet/DuckDB reuse, the public site and read-only MCP surfaces, domain-aware archival workflows, and recent correctness/performance maintenance.

S quality is withheld because coverage remains intentionally incomplete and heterogeneous across official sources, the stable public MCP URL is still pending its smoke proof, a current Internet Archive publishing handoff remains credential-blocked, and the breadth of supported and experimental pipelines creates meaningful integration burden. Interest is S because the project turns fragile judicial publications into provenance-aware, reusable public legal-data infrastructure rather than a closed search application.
