description: "Anuncia o resultado da cópia de blocos de código para tecnologias assistivas."
tags: [accessibility, ux]
---

Os botões de copiar código agora expõem o resultado de cada tentativa por uma região de status acessível, incluindo sucesso e falha. O status é limpo após o feedback visual para que ações repetidas com o mesmo resultado sejam anunciadas novamente.
