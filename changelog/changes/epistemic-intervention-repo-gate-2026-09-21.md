# Gate interventions per owner/repo

- Each public `owner/repo` gets at most one initial observatory intervention while unengaged.
- No reply or material uptake means no bump, second issue, attention-seeking PR or cross-post.
- Material progress opens the gate: substantive replies, experiments, commits/docs, claim revisions, references to the intervention or explicit requests allow further comments, issues and PRs in that same repository.
- If progress stops, the repository returns to waiting.
- Separate repositories owned by the same user are separate intervention targets; engagement in one does not automatically authorize intervention in another.
