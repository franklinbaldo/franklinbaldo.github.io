# Proveniência de claims + Schmidhuber Meter

- `schmidhuber_meter.md` entra no mapa como metodologia de metaciência/bibliometria: ciência C / interesse A / confiança medium. A fórmula v0.1 é auditável e concreta, mas ainda carece de calibração empírica, sensibilidade, concordância entre avaliadores e validação externa.
- `proveniencia_claims.md` passa de ciência B para C, mantendo interesse A / confiança medium. A mudança é material: a auditoria encontrou prior art forte para provenance genérica, backward tracing, estados unresolved e argument graphs; o residual defensável é a combinação status-sensitive cross-document, sobretudo contingent-in-source → load-bearing downstream com incerteza explícita.
- O mapa narrativo passa a ligar especificamente `Proveniência de claims` → `Schmidhuber Meter` → `Machine Discovery` como provenance → credit audit → epistemic admission.
