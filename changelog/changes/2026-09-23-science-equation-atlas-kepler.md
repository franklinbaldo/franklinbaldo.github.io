# Scientific Equation Atlas: Astronomy and Kepler's third law

The atlas adds an explicit Physics and Astronomy → Astronomy and Astrophysics path and the sourced solar-system form `P^2 = a^3`. The run checks the positive-domain transformation to `P = a^(3/2)`, makes the unit normalization explicit, compares it with the Newtonian generalized coefficient, rejects unsupported equation-family edges, and updates stale branch text that previously said astronomy had no formula occurrence.
