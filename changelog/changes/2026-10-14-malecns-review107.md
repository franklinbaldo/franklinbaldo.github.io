# MaleCNS evidence curation — review 107

Adds **Fly.exe / MaleCNS Virtual Fly** (`Ibtisam-Mohammad/Fly.exe`) as a new, independent public Markdown OKF card, at initial **scientific A / interest S / medium confidence**. The separate `shute2004/virtual-fly` project is not duplicated or changed. Evidence is pinned to commit `cc25411e00f945e7330cb6f400372cce315c0802`.

The repo reports a 12-fly, one-seed embodied demo (12/12 end near an object under visual input versus 0/12 stimulus-absent). The author explicitly calls it **presentation-grade** with no scientific validation tier. Locomotion uses an engineered gait, sensory input is symbolic geometry, and the flies are copies sharing one connectome; no social/swarm-behaviour, food recognition, or topology-specific causal advantage is established. Track A's 0/30 grooming-displacement failure and the restricted Stage 1 circuit-level positive result are preserved distinctly.
