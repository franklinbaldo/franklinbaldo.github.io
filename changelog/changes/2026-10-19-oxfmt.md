description: Replace Prettier with Oxfmt as the repository formatter
tags: [developer-experience, tooling, formatting]
---

The `format` and `format:check` scripts now use pinned Oxfmt, alongside
Oxlint. Formatting defaults preserve the previous 80-column width, trailing
commas, Markdown prose behavior, and the existing exclusion list. Repository
instructions and the root-file hygiene guard follow the new configuration.

The existing policy remains: global formatter checks are available for
manual audits and are not a blocking CI gate. No mass rewrite of historical
content is part of this tool replacement.
