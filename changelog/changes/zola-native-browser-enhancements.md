description: O build Zola passa a compilar cópia de código e diagramas Mermaid a partir de fontes TypeScript independentes do Astro.

As melhorias de cópia de código e Mermaid do site publicado deixam de ser extraídas de componentes `.astro` e passam a ter fontes TypeScript próprias para o Zola. A documentação de entrada também passa a identificar o Zola como gerador de produção. As demais dependências legadas continuam disponíveis enquanto sua substituição é testada.
