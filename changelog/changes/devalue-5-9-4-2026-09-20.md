# devalue 5.9.4

Updates `devalue` from 5.9.2 to 5.9.4.

The patch release includes upstream validation and serialization fixes, including tighter handling of null-prototype object keys, typed-array backing buffers, sparse arrays, repeated values, and Node Buffer slices, plus a tree-shaking optimization. No application API or architecture is intentionally changed.
