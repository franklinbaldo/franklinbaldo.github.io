One row per mode, brightness = |c|. Stable bands are fixed points; stripes that repeat are cycles; amber ticks mark a perturbation.

Empirical operator

Row = mode kicked, column = mode that changed. Cell = energy change 1–3 s after the kick versus just before it, minus the kick’s own passive decay, centred across kicked modes so only the kick-specific response remains. Cyan = gained energy, violet = lost. Kicks before the DNs are live, or within 3 s of another kick, are not recorded. Meaningful only after many kicks; 0 kicks.
