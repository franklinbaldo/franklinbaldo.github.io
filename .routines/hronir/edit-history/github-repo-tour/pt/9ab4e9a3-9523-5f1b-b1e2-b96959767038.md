Para mim, repositório é a forma mais barata de pensar uma ideia até ela falar comigo. Não é metáfora — é workflow. Eu começo escrevendo um README, e quando o README começa a discutir comigo, sei que vale fazer o resto. Tenho 64 repositórios públicos no [GitHub](https://github.com/franklinbaldo). Metade vai morrer sem leitor. Tudo bem.

Os que eu releio com prazer são poucos, e nem sempre os que recebem estrela. Começo por esses.
