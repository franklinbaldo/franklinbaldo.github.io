agent-no-verbs vence. O post parte de uma metáfora simples — o agente não inventa verbos — e a desenvolve em algo com implicações reais para alinhamento: um diretório de playbooks com conteúdo endereçado por hash é mais estável que qualquer sistema prompt porque a restrição é estrutural, não linguística. A observação de que um escritório jurídico brasileiro já funciona com essa lógica há décadas (ato existe somente quando reduzido a texto, cadeia de vistos, catálogo de permissões) transforma o que poderia ser mais um post técnico em algo com genealogia real. pierre-menard é inteligente — usar o personagem de Borges para discutir como pesquisa computacional pode reinventar o processo científico — mas o argumento central fica mais próximo de uma brincadeira filosófica do que de uma tese trabalhável. agent-no-verbs tem código, tem estrutura de diretório, tem consequências que se propagam para outros posts na série. É o post mais diretamente útil para quem quer construir agentes com comportamento previsível; pierre-menard é mais útil para quem quer pensar sobre o que é pesquisa.
