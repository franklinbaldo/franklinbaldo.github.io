limit: >-
  Connectomas como reservoirs, reservoir computing para NLP e até MaleCNS + linguagem + readout congelado já têm antecedentes próximos. O pacote exato de tagging jurídico byte-level com null recorrente degree-preserving e baseline sem recorrência não foi localizado antes do cutoff, mas busca negativa não prova novidade; o corpus é minúsculo e o v2 usa validação para seleção de checkpoint, então só uma avaliação posterior no test split untouched pode fortalecer claims de desempenho.
