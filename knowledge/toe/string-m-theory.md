# String theory / M-theory

A mature unification programme with increasingly explicit controlled recovery calculations and major unresolved empirical and vacuum-selection questions. r107 adds arbitrary-n AdS3 KZ residue machinery and a two-loop M2/ABJM instanton check; the placement remains A/S.
