# Audiobook Factory skills

Versioned operational skills for agents working on the Audiobook Factory.

- `audiobook-editorial-segment/SKILL.md` — advance exactly one canonical source -> translation -> narration editorial unit, preserving identity, lineage, project prerequisites and readiness boundaries.
- `audiobook-tts-payload/SKILL.md` — create/review narration shards under the executable `tts-body-v1` contract: control information in frontmatter, exact synthesizer payload in the body.

These skills explain how to perform the work. `scripts/audiobook/validate-okf.py` remains the mechanical enforcement boundary. Specs and guides under `docs/okf/audiobook/` remain the normative project documentation.
